# Ansible PDG Defect Dataset Artifacts

This folder contains the tracked dataset artifacts selected from the second PDG
extraction run and the final versioned dataset produced from them.

## Contents

- `radon/ansible-pdg-defect-dataset_rows_successful_extracted.csv`: RADON-derived rows successfully extracted during the run.
- `pdg_extraction/extraction_status.csv`: PDG extraction status, including 37.834 successfully extracted PDGs (where status = "SUCCESS") and their related paths.
- `pdg_extraction/run_metadata.json`: metadata for the extraction run that produced these artifacts.
- `final/v2026-06-06/`: final versioned dataset with RADON metrics, PDG paths,
  PDG metrics, manifest and exclusion report.

## Final Dataset Version

The current final dataset is:

```text
final/v2026-06-06/ansible-pdg-defect-dataset_v2026-06-06_final.csv
```

It was generated by `dataset_preparation/scripts/build_versioned_dataset.py`
from:

- `output/second_pdg_extraction/input_dataset.csv` as the complete RADON source
  with 61.542 rows and 130 RADON columns;
- `pdg_extraction/extraction_status.csv` as the PDG extraction status source.

Important counts:

| Stage | Rows |
|---|---:|
| RADON filtered input | 61.542 |
| PDG extraction `SUCCESS` | 37.834 |
| PDG metrics extracted | 37.796 |
| Final dataset rows | 37.796 |

Final label distribution:

| `failure_prone` | Rows |
|---:|---:|
| 0 | 23.880 |
| 1 | 13.916 |

The final folder also contains:

- `ansible-pdg-defect-dataset_v2026-06-06_exclusions.csv`: one primary exclusion reason per
  removed row;
- `ansible-pdg-defect-dataset_v2026-06-06_pdg_metrics.csv`: computed PDG metric table;
- `manifest.json`: input/output paths, parameters and stage counts;
- `DATASET_REPORT.md`: human-readable history of the dataset version;
- `reports/`: quality tables for labels, repositories, statuses, exclusions and
  PDG metric summaries.

## Notes

The final dataset keeps only rows with a successful PDG extraction and a readable
GraphML graph meeting the conservative quality threshold configured for the
extraction run:

```text
min_pdg_nodes = 3
min_pdg_edges = 2
```

This makes the dataset suitable as the common sample set for the tabular
baselines, tabular+PDG baselines and GNN experiments.
